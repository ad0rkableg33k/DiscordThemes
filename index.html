On a Mac

macOS can't change cursors by itself, so you need a free helper app. It needs macOS 15 Sequoia or newer.

  1. Download a pack above and double-click the zip to unzip it.
  2. Get MaCursor: on its Releases page, download the .dmg, open it, and drag MaCursor into Applications.
  3. Open MaCursor and choose File → Convert Theme….
  4. Pick the theme folder from the unzipped pack (for example Midnight-Sorrow). Use the -small-32px folder if the cursors look too big.
  5. Select the new theme in MaCursor's library and apply it. Follow any permission prompt MaCursor shows.

On Windows

Easiest: use the Windows one-click (.bat) button on your theme above. It's a single file, so there's no unzipping and no hunting through Settings.

  1. Download the .bat file. If your browser or Windows warns about it, choose Keep, then More info → Run anyway. That warning shows up for any downloaded script. You can open the file in Notepad first to read exactly what it does.
  2. Double-click it. A window opens with three choices.
  3. Type 1 for the normal size or 2 for the small one, then press Enter. Your cursors change right away.
  4. To go back, run the same file and type 3.

It only changes the pointer settings for your own Windows account. Nothing is installed besides the cursor files.

Prefer the zip?

  1. Download a pack above, right-click the zip and choose Extract All.
  2. Open the theme folder inside (for example Midnight-Sorrow), right-click install.inf and choose Install.
  3. Open Settings → Bluetooth & devices → Mouse → Additional mouse settings and go to the Pointers tab.
  4. Pick the theme's name in the Scheme dropdown and click Apply.

Just in case

  • No install.inf option or the scheme is missing? On the Pointers tab, select a cursor in the list, click Browse, and pick the matching .cur file by hand. Pointer.cur is the normal arrow, Link.cur is the hover hand, and Busy.cur is loading.
  • On macOS 14 or older? MaCursor won't run. The older Mousecape app may work, but it isn't reliable on current systems.
  • These cursors only change your system pointer. The Discord themes already include their own cursors inside Discord.

Installation

  1. Open Discord and go to User Settings (the gear icon next to your username).
  2. Scroll to the Equicord section in the sidebar and click Themes.
  3. Click the folder icon ("Open Themes Folder") near the top of the page — this opens the local folder Equicord loads .theme.css files from.
  4. Click the Download button on any theme above. The file downloads automatically, then move it into that folder.
  5. Back in the Themes tab, the theme will show up in the list — toggle it on.
  6. Reload Discord (Ctrl+R / Cmd+R) if anything looks off.

You can install more than one at once — they won't conflict, so switch between them whenever the mood changes.

Just in case

  • Theme doesn't show up? Check the file name. Some browsers save it as .css instead of .theme.css. It has to end in .theme.css, so rename it if needed.
  • Browser asks where to save it? Save it straight into the Equicord themes folder from step 3.
  • Something looks off? Reload Discord with Ctrl+R / Cmd+R.
