Installation

  1. Open Discord and go to User Settings (the gear icon next to your username).
  2. Scroll to the Equicord section in the sidebar and click Themes.
  3. Click the folder icon ("Open Themes Folder") near the top of the page — this opens the local folder Equicord loads .theme.css files from.
  4. Click the Download button on any theme above. The file downloads automatically, then move it into that folder.
  5. Back in the Themes tab, the theme will show up in the list — toggle it on.
  6. Reload Discord (Ctrl+R / Cmd+R) if anything looks off.

You can install more than one at once — they won't conflict, so switch between them whenever the mood changes.

Just in case

  • Theme doesn't show up? Check the file name. Some browsers save it as .css instead of .theme.css. It has to end in .theme.css, so rename it if needed.
  • Browser asks where to save it? Save it straight into the Equicord themes folder from step 3.
  • Something looks off? Reload Discord with Ctrl+R / Cmd+R.
